# План проекта

| Этап | Статус | Проверка |
| --- | --- | --- |
| Уточнить сценарий и границы | Готово | Сверили расписание, SQLite и семь критериев готовности с официальным `spec.md`. |
| Запустить страницу и SQLite | Готово | `npm start` на Node.js 26.3.0 с чистым файлом SQLite. Сервер создал обе таблицы и пять строк на текущую дату по Москве. |
| Реализовать запись | Готово | Запись на `11:00` прошла. Второй запрос из открытой формы показал понятный отказ. Одновременные запросы дали `303` и `409`, первое ФИО сохранилось. |
| Добавить последнее кормление | Готово | Поле «Кто покормил Бориса?» принимает ФИО. После второй отметки обе сессии показали последнее ФИО и одно время. После перезапуска запись и кормление сохранились. |
| Собрать доказательства и архив | Готово | Семь PNG, короткое демо, карточка кейса и след итерации включены в архив. Запуск из распакованной копии проверен на отдельной базе. |

## Ветка для сдачи

Для первого спринта используем ветку `sprint_1`. Пул-реквест открывается из этой ветки своего форка в `main` учебного репозитория `yandex-praktikum/ai-tools-for-pdm`.
