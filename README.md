
# Агент-диспетчер по возвратам

Учебный проект Яндекс Практикума для компании «Клевер Маркет».

## Назначение

Приложение помогает менеджеру обрабатывать обращения клиентов о возврате товаров.

ИИ-агент:
- читает обращение клиента;
- находит соответствующий заказ;
- проверяет историю возвратов;
- применяет политику возвратов и правила категории;
- рекомендует маршрут обработки;
- готовит черновик ответа клиенту;
- составляет комментарий для менеджера.

Окончательное решение принимает только менеджер.

## Технологии

- Python 3.13
- Flask
- SQLite
- OpenRouter API
- HTML, CSS, JavaScript

## Маршруты агента

1. RECOMMEND_APPROVE — рекомендовать одобрение.
2. RECOMMEND_DENY — рекомендовать отказ.
3. NEED_MORE_INFORMATION — запросить недостающие сведения.
4. MANUAL_REVIEW — передать на ручную проверку.
5. DUPLICATE_OR_PROCESSED — повторное или обработанное обращение.

## Подготовка к запуску

Создать виртуальное окружение:

```bash
python3.13 -m venv .venv
```

Активировать его на macOS:

```bash
source .venv/bin/activate
```

Установить зависимости:

```bash
pip install flask python-dotenv openai
```

Создать файл `.env` в корне проекта и указать:

```env
OPENROUTER_API_KEY=ваш_ключ_OpenRouter
MANAGER_API_KEY=ваш_секретный_ключ_менеджера
```

Настоящие ключи нельзя публиковать в GitHub.

## Подготовка SQLite

Выполнить в терминале:

```bash
python -c 'from database import initialize_database, initialize_analysis_table, add_manager_reason_column; initialize_database(); initialize_analysis_table(); add_manager_reason_column()'
```

Таблица учебных разрешений на возврат создаётся приложением при подтверждении решения менеджера.

## Запуск приложения

```bash
python -c "from app import app; app.run(port=5001, debug=True)"
```

Открыть в браузере:

http://127.0.0.1:5001/

Режим debug предназначен только для локальной разработки.

## Обработка обращений

В приложении доступно 16 учебных обращений: RC-6001–RC-6016.

Для каждого дела отображаются:
- письмо клиента;
- данные заказа;
- история обращений;
- рекомендация ИИ;
- обоснование;
- недостающие сведения;
- черновик ответа клиенту;
- комментарий менеджеру.

Сохранённые анализы загружаются из SQLite без повторного запроса к ИИ.

Для обработки обращений, ещё не имеющих сохранённого анализа, предусмотрен скрипт:

```bash
python test_ai.py
```

Для экспорта результатов в Markdown:

```bash
python export_results.py
```

Результаты сохраняются в `case-results.md`.

## Подтверждение менеджером (human gate)

ИИ не принимает окончательных решений.

Менеджер может:
- подтвердить рекомендацию об одобрении или отказе;
- изменить рекомендацию с обязательным указанием причины;
- оставить обращение без окончательного решения, если необходима ручная проверка или дополнительная информация.

Итоговое решение сохраняется в SQLite.

Учебное разрешение на возврат создаётся только при сочетании:

- маршрут ИИ: `RECOMMEND_APPROVE`;
- подтверждённое решение менеджера: `APPROVED`.

Повторное подтверждение решения блокируется.

## Ограничения безопасности

Приложение:
- не выполняет банковских операций;
- не меняет заказы во внешних системах;
- не отправляет письма клиентам автоматически;
- не выдаёт реальные разрешения на возврат;
- требует ключ менеджера для защищённых действий.

Клиентские письма остаются черновиками до решения человека.

## Структура проекта

- `app.py` — Flask API.
- `ai_client.py` — подключение ИИ и проверка ответа.
- `auth.py` — проверка ключа менеджера.
- `database.py` — работа с SQLite.
- `decision_rules.py` — проверка допустимых маршрутов.
- `templates/index.html` — интерфейс.
- `data/` — исходные учебные обращения и заказы.
- `policy/` — политика возвратов и правила категорий.
- `test_ai.py` — обработка очереди.
- `export_results.py` — экспорт таблицы результатов.
- `case-results.md` — результаты 16 обращений.

## Ограничения ИИ

Ответы внешней модели могут содержать ошибки формата или интерпретации правил.

Поэтому приложение проверяет структуру ответа и допустимость маршрута. Рекомендации ИИ требуют проверки менеджером.

Проект предназначен исключительно для учебного использования.


## Восстановление стартовых данных

Для восстановления учебной базы выполните:

```bash
python reset_data.py
```

Скрипт создаёт необходимые таблицы SQLite,
очищает предыдущие учебные решения и разрешения
и восстанавливает 16 сохранённых анализов из
`data/seed-analyses.json`.

Рекомендации ИИ сохраняются, а окончательные решения
менеджера становятся неподтверждёнными.

Повторный вызов языковой модели для восстановления
сохранённых результатов не требуется.

## Журнал событий

В карточке каждого обращения отображается
раздел «Журнал событий».

Приложение фиксирует:
- выбранный маршрут и использованные источники;
- обнаруженные повторные обращения;
- необходимость ручной проверки или дополнительных сведений;
- подтверждение решения менеджером;
- отказ в возврате;
- выдачу учебного разрешения.

Журнал хранится в SQLite. API-ключи, полные письма
клиентов и другие лишние персональные данные
в журнал не записываются.
