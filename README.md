# Кто выгуливает Бориса

Общая страница записи на прогулки и отметки последнего кормления для вымышленной компании «Догяндекс».

## Запуск

Нужны Node.js 24.2 или новее и npm. Приложение использует встроенный `node:sqlite` и запускается из корня проекта одной командой.

```sh
npm start
```

Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000). Сервер создаст `data/boris.sqlite` при первом запуске. При перезапуске используется тот же файл. Для чистой проверки укажите новый путь к базе и, если нужно, другой порт.

```sh
DB_PATH=./data/boris-check.sqlite PORT=3001 npm start
```

## Проверка

1. Откройте одну страницу в двух независимых браузерных сессиях. Проверьте московскую дату и пять слотов `09:00`, `11:00`, `13:00`, `15:00`, `17:00`.
2. В обеих сессиях начните запись на `11:00`. В первой подтвердите запись на имя «Анна Тестова». Во второй отправьте оставшуюся открытой форму с именем «Илья Примеров». Ожидается сообщение, что слот уже занят. В расписании должно остаться первое ФИО.
3. Обновите обе страницы. Введите «Илья Примеров» в карточке кормления, отметьте кормление и обновите страницу в другой сессии. Там должны появиться время и ФИО.
4. Перезапустите сервер с тем же файлом базы. Проверьте запись и кормление. Повторите запись на другой свободный слот в узком окне браузера.

## Границы

Общая страница с расписанием на текущую дату и карточкой последнего кормления. Авторизация, отмена записи, недельный календарь, уведомления, интеграции и общий интернет-доступ вне рамок MVP. Для проверки используются синтетические данные.

Требования и схема базы — в [spec.md](spec.md). Результаты проверок — в [PLAN.md](PLAN.md).
