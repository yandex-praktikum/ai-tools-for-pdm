# Кто выгуливает Бориса

Учебный Node.js micro-MVP для вымышленной компании «Догяндекс». Все ФИО и
данные в проекте синтетические.

## Что такое Vibe

Vibe — рабочий контур для создания, проверки и публикации проектов с помощью
Codex.

## Назначение

Приложение помогает сотрудникам самостоятельно распределить пять прогулок с
офисным псом Борисом на текущую дату и увидеть последнее кормление.

Реализовано:

- текущая дата и ровно пять слотов: `09:00`, `11:00`, `13:00`, `15:00`, `17:00`;
- визуально различимые свободные и занятые слоты;
- запись в свободный слот по непустому ФИО;
- атомарный серверный отказ при повторной записи без замены первого ФИО;
- постоянное хранение прогулок и кормлений в SQLite;
- карточка последнего кормления с пустым состоянием, ФИО и временем;
- компоновка для широкого и узкого экрана.

## Локальный запуск

Требуется Node.js 24 с поддержкой встроенного модуля `node:sqlite`.

Установите зависимости:

```bash
npm ci
```

Запустите приложение:

```bash
HOST=127.0.0.1 PORT=3000 npm start
```

После сообщения `Приложение запущено: http://localhost:3000` откройте
`http://localhost:3000` в браузере.

При первом запуске в корне проекта создаётся `boris.sqlite`. Приложение создаёт
таблицы `walk_slots` и `feedings`, а также недостающие пять свободных слотов
текущей даты. Файл базы и его служебные файлы не добавляются в Git.

Для изолированного запуска можно явно задать другой путь к базе:

```bash
SQLITE_PATH=/tmp/boris-test.sqlite HOST=127.0.0.1 PORT=3000 npm start
```

## Главный сценарий прогулки

1. Откройте страницу и выберите свободный слот.
2. Введите синтетическое ФИО, например «Анна Тестова».
3. Нажмите «Записаться» и убедитесь, что слот стал занятым и показывает ФИО.
4. Из ранее открытой страницы второго браузера отправьте форму того же слота с
   другим синтетическим ФИО, например «Илья Примеров».
5. Сервер вернёт конфликт, страница покажет понятное сообщение, а первая запись
   останется без изменений.
6. После обновления страницы или открытия во втором браузере состояние останется
   тем же, поскольку оно читается из SQLite.

ФИО проверяется сервером после удаления крайних пробелов. Пустое значение или
строка из пробелов не сохраняется.

## Последнее кормление

До первой отметки карточка сообщает, что кормление ещё не отмечали. Введите
синтетическое ФИО и нажмите «Отметить кормление»: карточка покажет ФИО и время.
Каждая отметка сохраняется в `feedings`, а интерфейс показывает последнюю.

## Проверка

Контролируемый smoke-check из `spec.md` пройден автоматически на отдельной
SQLite-базе и вручную на опубликованной версии. Подтверждены семь DoD: дата и
пять слотов, состояния слотов, успешная запись, серверный конфликт, постоянство
SQLite, последнее кормление и работа на широкой и узкой ширине.

Опубликованная учебная версия доступна без авторизации:
[https://vibe-apps.aikibox.ru/sprint-1/](https://vibe-apps.aikibox.ru/sprint-1/).

## Системные файлы и папки Vibe

Общий контур Vibe использует `CONSTITUTION.md`, `INDEX.md`, `VALUES.md`, файлы
в `docs/`, каталог `materials/`, служебный каталог `.codegraph/`, а также
`Containerfile` и `publish.json` для публикации. `.git/` относится к Git,
`node_modules/` создаётся npm, а `boris.sqlite` — самим приложением. Служебные и
генерируемые каталоги не следует редактировать вручную без необходимости.

## Границы

Это учебный micro-MVP, а не промышленная внутренняя система. В проект не входят
регистрация, авторизация, роли, корпоративный SSO, отмена и администрирование
записей, уведомления, календарь на неделю, пользовательский интерфейс истории,
несколько собак, внешние интеграции и production-grade эксплуатация.

SQLite хранит техническую последовательность кормлений только для определения
последней отметки. Интерфейса истории кормлений нет.

Единственный источник продуктовых требований — актуальный `spec.md`.
