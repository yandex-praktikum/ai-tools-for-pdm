# Описание

Учебный micro-MVP для вымышленной компании «Догяндекс».
Страница позволяет сотруднику записаться на прогулку с офисным псом Борисом в один из пяти слотов и отметить факт кормления.

## Возможности

- показ текущей даты и пяти фиксированных слотов прогулок (09:00, 11:00, 13:00, 15:00, 17:00);
- выбор свободного слота и ввод ФИО;
- подтверждение записи;
- визуальное различие свободного и занятого слота; у занятого видно ФИО записавшегося;
- защита от повторной записи в занятый слот на сервере;
- отметка факта кормления: карточка «Последнее кормление» показывает время и ФИО покормившего последним;
- хранение записей на прогулки и отметок кормления в SQLite;
- главный сценарий читаем и выполним на широком и узком экране.

## Технологии

- HTML5, CSS, JavaScript;
- Node.js + npm;
- SQLite.

## Запуск

Нужен установленный Node.js (v22+ со встроенным `node:sqlite`) и npm. Внешних зависимостей нет, поэтому достаточно:

```bash
npm start
```

- Страница: [http://localhost:3000](http://localhost:3000)
- Другой порт: `PORT=3001 npm start`
- Остановка: `Ctrl+C`
- Файл базы `data/boris.db` создаётся при первом запуске; слоты на новую дату — автоматически при открытии страницы.

## Проверка

Краткий smoke-check после изменений (полный список — в `spec.md`):

1. на странице видны текущая дата и пять слотов;
2. записаться в свободный слот с синтетическим ФИО;
3. повторная запись в тот же слот — понятный отказ, исходная запись не меняется;
4. после обновления страницы запись на месте;
5. отметить кормление — карточка обновилась;
6. сценарий читаем на широком и узком экране.
