# Частная конституция: sprint_1

Версия: 0.5

Статус: требует уточнения по мере развития проекта

Владелец: пользователь

## Назначение

`sprint-1` — самостоятельный прикладной проект. Целевой пользовательский
результат, границы продукта и критерии успеха должны быть уточнены и зафиксированы
здесь перед значимым product decision.

## Принципы

1. Проект имеет отдельную папку, Git history, документацию, данные и lifecycle.
2. Фактическое поведение, код, архитектура и документация не должны расходиться.
3. Секреты не попадают в Git, чат, command arguments или обычные логи.
4. Существенное изменение проверяется и фиксируется в Git с понятным rollback.
5. Ценности проекта фиксируются в `VALUES.md` и направляют выбор между
   несколькими допустимыми решениями.
6. Полезные общие практики могут быть предложены для продвижения в проект-систему.
7. Крупные uploads, generated artifacts и exports хранятся в полностью
   ignored `materials/` внутри project root, а не в Git history.
8. Новые созданные по запросу пользователя некодовые артефакты по умолчанию
   сохраняются в `materials/generated/`, если пользователь не указал другой путь.
9. Крупные импорты, экспорты, render и build имеют потоковую или пакетную
   реализацию, явный бюджет памяти и проверку peak RSS на репрезентативном
   объёме; инфраструктурный лимит не используется для маскировки накопления
   полного набора в RAM.

## Граница системы

Этот проект не управляет сервером. В его контексте ИИ-оператор не изменяет
`/srv/vibe/system`, общую инфраструктуру или другие проекты без явного
разрешения пользователя в текущем диалоге.
